# Argos handoff

Current branch: `windows-capture`. The [approved design](docs/superpowers/specs/2026-11-18-argos-design.md) and [Windows capture plan](docs/superpowers/plans/2026-11-18-windows-capture.md) apply. Windows first, then macOS and Linux. Provider keys are preferred. The design also covers eligible ChatGPT plan access for Codex and the separate Claude Code handoff option for Claude subscribers. The Claude and Codex integrations follow Windows capture validation.

The first Tauri app includes a Windows picker, WGC frame counts and dimensions, WASAPI playback counts and peak level, and Start/Stop. The Rust worker drops samples after measuring them. Closing the window requests cancellation and joins the worker off the UI thread. The worker uses Windows bindings directly for cancellable selection, free-threaded frame capture, and handle ownership. No windows-capture wrapper is required.

Validated on Apple Silicon: five portable lifecycle tests passed, Rust formatting and host Clippy passed, the UI Start/Stop, meter, and error states passed a simulated IPC smoke check, and the Windows x64 GNU release executable and Windows test executables cross-linked. The generated capability restricts the three capture commands to the local main window. The locally built portable archive at `dist/Argos-Windows-x64.zip` was verified against the release executable and its required WebView2Loader.dll. The Windows/MSVC CI job is checked in; no remote CI run or interactive Windows test has been recorded.
