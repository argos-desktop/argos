# Argos handoff

Current branch: `macos-capture`, based on `windows-capture`. The owner has a Mac available now. Use it for development and live validation while Windows hardware validation is pending. Linux follows later. The [design](docs/superpowers/specs/2026-11-18-argos-design.md) covers provider keys, eligible ChatGPT subscription access for Codex, and the separate Claude Code handoff option for Claude subscribers. Both desktop builds currently perform local capture only.

macOS 14+ uses ScreenCaptureKit's native sharing picker and one stream for screen frames and playback audio. The Rust backend reports dimensions, counts, and peak level through the same three main-window commands as Windows. The Windows backend uses Windows Graphics Capture and WASAPI loopback. Neither backend saves media or calls a provider.

Validation on Apple silicon, macOS 27.0.1: six tests passed, including the PCM meter and session lifecycle tests. The macOS window showed Idle, Start entered source selection, and Stop returned it to Idle with zero frames before a source was selected. Mac Clippy passed. The Apple silicon release bundle at `dist/Argos.app` passed strict ad hoc signature verification, and `dist/Argos-macOS-arm64.zip` passed its archive check. The Windows x64 GNU release cross-linked during this port. No interactive Windows result or remote CI run has been recorded.
